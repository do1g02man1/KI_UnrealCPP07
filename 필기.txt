* Unreal Framework
*	- GameMode : 각 레벨의 규칙 설정, 레벨별로 설정 가능
*	- Actor : 레벨에 배치되는 모든 오브젝트가 상속 받는 클래스
*	- Pawn : Controller로 조종할 수 있는 특수한 액터 (Actor를 상속받았음)
*	- Charactor : Pawn에 휴머노이드 특성을 더 추가한 클래스 (Pawn을 상속 받았음)
*	- Controller : 폰에 행동을 지시할 수 있게 해주는 클래스. Pawn에 Controller를 붙이는 것을 빙의(Possess)라고 함

* 조명 (Light)
*	- 디렉셔널 라이트 (Dirctional Light)
*		- 방향만 있는 조명
*		- 게임 월드에 전역적으로 한 방향에서 빛이 들어와야 될 때 사용하는 조명
*		- 예시) 태양광
*	- 포인트 라이트 (Point Light)
*		- 한 점에서 특정 반경 내에 빛을 뿌리는 조명
*		- 거리가 멀어질수록 빛이 약해진다.
*		- 예시) 횃불, 폭발, 전구 등 작은 광원.
*	- 스포트 라이트 (Spot light)
*		- 한 점에서 특정 방향으로 원뿔 모양으로 빛을 뿌리는 조명
*		- 원뿔의 중심부에서 멀어질수록 빛이 약해진다.
*		- 예시) 무대 조명, 자동차 헤드라이트, 손전등 등
*
*	- 렉트 라이트 (Rect Light)
*		- 직사각형 면에서 빛이 나오는 조명
*		- 예시) 형광등, 네온사인, TV화면, 창문 등
*	- 스카이 라이트 (Sky Light)
*		- 하늘의 밝기나 색을 전체 씬에 골고루 적용하는 환경광
*		- 예시) 실외 배경, 전역적인 간접광

* 머티리얼 (Material)
*	- 3D 모델의 표면에 적용되어 색상, 질감, 빛 반사 등 시각적 특성을 결정하는 데이터
*
* 물리 기반 랜더링 / PBR(Physically Based Rendering)
*	- 실제 세계의 빛과 재질이 상호 작용하는 방식을 물리 법칙에 기반하여 시뮬레이션하는 랜더링 기법
*	- 직관적이고 자연스럽다.
*	- 주요 속성
*		- Base Color : 물체의 기본 색상
*		- Metalic : 금속성 정도 (0이면 비금속, 1이면 금속)
*		- Roughness : 표먼의 거칠기 (0이면 매끄러움, 1이면 거침)
*		- Normal : 표면의 법선 벡터

* 좌표계 
*	- 위치를 표시하기 위한 방법
*	- x, y, z 값으로 3차원 3D 공간의 위치를 표시
*	- 왼손 좌표계, 오른손 좌표계
*	- 3D 그래픽스에서 일반적으로 왼손 좌표계를 사용한다
*		- 언리얼에서는 회전된 왼손 좌표계를 사용
*			- x : 앞쪽(Forward), y : 오른쪽(Right), z : 위쪽(Up)
*			- x축, y축 회전은 반시계 방향이 +
*			- z축 회전은 시계 방향이 +
* 로컬 좌표계
*	- 액터의 원점을 기준으로 한 좌표계
* 월드 좌표계
*	- 월드의 원점을 기준으로 한 좌표계

* 벡터
*	- 힘의 크기와 방향을 표현

* 언리얼 블루프린트의 코드 분류 방법 
*	- 이벤트
*		- 리턴값이 없다
*		- 재사용성은 떨어짐 (로컬 변수 없음)
*	- 함수
*		- 리턴 값이 있음
*		- 딜레이는 안됨
*	- 매크로
*		- 리턴 값이 있음
*		- 딜레이도 됨
*		- 로컬 변수 없음 (이벤트 내용을 정리하는 느낌)

* 언리얼의 회전
*	- Yaw : Z축 회전
*	- Pitch : Y축 회전
*	- Roll : X축 회전
*
* 오일러 앵글 (Euler Angle)
*	- 회전을 x, y, z축이 각각 얼마씩 회전했느냐로 표현
*
* 짐벌락
*	- 오일러 앵글을 사용할 대 하나의 축이 잠기는 현상
*
* 쿼터니언
*	- 숫자 4개로 회전을 표현하는 방법
*	- 장점
*		- 계산이 빠르다
*		- 메모리도 적게 차지한다
*	- 단점
*		- 사람이 알아보기 힘들다

* 보간
*	- 시작 값과 마지막 값이 있을 때 중간 값을 구하는 것

* 블루프린트간의 통신
*	- 직접 참조
*		- 오브젝트 레퍼런스를 통해 통신
*	- 인터페이스
*		- 서로 다른 블루프린트에게 공통된 기능을 부여하여 통신
*		- 상속 받고 구현이 되어 있을 때만 실행이 된다.
*		- 실행 시도는 누구나 가능하다.
*		- 결합도를 매우 쉽게 떨어트릴 수 있다.
*	- 이벤트 디스패처
*		- 하나의 블루프린트가 다수의 다른 블루프린트에게 특정 사건이 일어났음을 알리는 1:N 통신

* 비헤이비어 트리의 노드
*	- 컴포짓 (Composite) 노드
*		- 비헤이비어 트리의 흐름을 결정
*		- Selector 
*			- OR와 유사 (자식 중 하나라도 성공이면 이 셀렉터도 성공)
*			- 자식 중 하나라도 성공하면 즉시 멈추고 부모에게 성공을 반환
*			- 모든 자식이 실패하면 부모에게 실패를 반환
*		- Sequence
*			- AND와 유사 (모든 자식이 성공해야 이 셀렉터도 성공)
*			- 자식 중 하나라도 실패하면 즉시 멈추고 부모에게 실패를 반환
*			- 모든 자식이 성공해야 부모에게 성공을 반환
*
*	- 태스트 (Task) 노드
*		- 실제 실행을 하는 노드
*		- 블랙 보드의 내용을 일겅서 행동 수행
*
*	- 데코레이터 (Decorator) 노드
*		- 실행 조건 판정
*		- 블랙 보드의 내용을 읽어서 판단을 내림
*
*	- 서비스 (Service) 노드
*		- 주변을 감지해서 블랙 보드에 정보를 쓴다.

* 언리얼 C++ 개요

* 언리얼 C++와 블루프린트의 관계
*	- 서로 계층이 다르다.
*	- C++는 블루프린트의 내용을 알 수 없다.
*	- 블루프린트는 C++의 내용을 허가 정도에 따라 알 수 있다.

* 언리얼 데이터 타입
*	- 언리얼은 C++의 표준 라이브러리를 사용하지 않는다.
*	- 자체적으로 대부분의 타입과 라이브러리를 구현함.
*		- ex) int => int32

* 문자열 타입
*	- FString : 일반 문자열 (std::string과 유사)
*	- FName : 이름 붙이기 용도. 빠르게 비교와 메모리 절약을 위한 불변 문자열. 대소문자 구분 없음.
*	- FText : 현지화 지원 문자열. 

* 컬렉션 타입 (데이터 컨테이너, 템플릿 기반)
*	- TArray : std::vector와 같은 컬렉션. 블루프린트 완전 지원.
*	- TMap : std::unordered_map와 같은 컬렉션. 키-값 맵. 순서 보장 안됨. 블루프린트 일부 지원.
*	- TSet : std::unordered_set과 같은 컬렉션. 유니크한 목록 저장용. 블루프린트 일부 지원.

* 트랜스폼 및 수학 타입
*	- FVector : 위치, 방향, 벡터
*	- FRotator : 회전 (오일러 각도)
*	- FQuat : 회전 (쿼터니언)
*	- FTransform : 위치, 회전, 스케일 모두 저장
*	- FMath 라이브러리 : 다양한 수학용 정적 함수 제공 

* 스마트 포인터
*	- 할당한 메모리가 더 이상 사용되지 않을 때 자동으로 해제해주는 포인터
*	- 일반 클래스용
*		- TSharedPtr, TWeakPtr, TUniquePtr
*	- UObject용
*		- **TObjectPtr**, TWeakObjectPtr, TSoftPtr, **TSubclassOf**, TSoftClassPtr

* 언리얼 핵심 클래스
*	- UObject
*		- 모든 언리얼 오브젝트의 최상위 부모 클래스
*		- 가비지 컬렉션으로 메모리 관리
*		- 모든 자식 클래스는 이름에 U를 접두사로 붙인다. (자동으로 붙음)
*		- 레벨에 직접적으로 존재하지 않고데이터 관리나 로직에 사용된다.
*	- AActor
*		- 레벨 내에 직접적으로 존재하고 Transform (위치, 회전, 스케일)을 가진다.
*		- AActor의 자식 클래스는 A를 접두사로 붙인다. (자동으로 붙음)
*		- AActor는 여러 UactorComponent를 포함시켜 다양한 기능을 확장
*	- UActorComponent
*		- AActor에 부착되어 기능을 확장
*		- 단독으로 월드에 존재할 수 없다. 반드시 액터에 부착되어야 한다.
*		- 자식 클래스는 U를 접두사로 가진다.
*		- 자체 Tick함수가 존재한다.

* 반드시 C++로 구현해야 할 요소들 (무조건무조건무조건)
*	- 구조체, enum, 인터페이스
*	- 블루프린트로 만들어진 것은 C++에서 확인이 불가능하기 때문에
